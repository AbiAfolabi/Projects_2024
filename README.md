### Project Description:
In this project, I will apply supervised learning techniques to a real-world data set and use data visualization tools to communicate the insights gained from the analysis.

The data set for this project contains information on "Life Expectancy" and is available as a free download on Kaggle.
The project will involve the following tasks:

-	Exploratory data analysis and pre-processing: I will import and clean the data sets, analyze and visualize the relationships between the different variables, handle missing values and outliers, and encode any categorical column.
-	The ultimate goal of the project is to gain hands-on experience on performing EDA and communicate insights to stakeholders using appropriate visualizations.
